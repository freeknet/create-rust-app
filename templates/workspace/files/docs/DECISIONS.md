# Decisions

This is an append-only log of choices that are not obvious from the code.
Each entry records the decision, why it was made, and what would reopen it.
To reverse a decision, add a new entry; an addendum to the old one is fine.

Each decision lives in `decisions/D<number>.md`, headed
`# D<number>: <decision> (<date>, <author>)`. Use the next unused number,
checking the main branch and open pull requests to avoid collisions.
