# D1: workspace layout (@@year@@, @@author@@)

Keep the desktop app in `crates/@@appCrate@@` and repository automation in
`crates/xtask`. The root manifest owns dependency versions, package metadata,
lint policy and build profiles. Members inherit them instead of drifting apart.

`cargo xtask ci` runs the local checks; `cargo xtask changelog` rebuilds the
changelog from conventional commits. A Rust tool works on Windows and Linux
and is checked alongside the app by workspace builds.

New reusable components can become sibling crates when a real boundary emerges.
Do not split modules into crates solely to grow the workspace.

**Would reopen:** the app becomes a small standalone library, or automation
needs to run without a Rust toolchain.
