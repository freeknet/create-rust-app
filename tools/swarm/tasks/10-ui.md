Implement `src/ui/{tty,rainbow,banner,theme,spinner,summary}.js` exactly to the "UI API" section of
docs/CONTRACTS.md and the UX section of docs/PLAN.md (the "Prism" banner the user approved — match it).

- Zero deps beyond `picocolors` (optional). Truecolor `\x1b[38;2;r;g;bm`; ansi256 fallback maps the
  hue to the nearest xterm-256 cube colour; ansi16 maps to the 6 bright colours; `none` = plain text.
- `detect()` per PLAN tiers. `animate` = tty && tier is truecolor/ansi256 && !process.env.CI.
  `unicode` false when `TERM=dumb` or (win32 and no WT_SESSION/TERM_PROGRAM and not VS Code).
  ASCII fallbacks: `◆`→`*`, `◇`→`-`, `━`→`=`, `✔`→`[ok]`, box chars → `+-|`, braille spinner → `-\|/`.
- `showBanner`: hide cursor while animating, always restore it (also on SIGINT), ~30 frames × 33 ms,
  rewriting the two lines in place, settle on the last frame, print one blank line after.
- `summary.js`: gradient rule, `✔ create-rust-app scaffolded <name>`, a two-column key/value table
  (kind, stack, edition · MSRV · toolchain, licence, crates, features on, tooling on), the file tree
  to depth 2 from `dests` (dirs tinted, `… N more` cap per dir), then a rounded "Next" box with
  `cd <dir>`, `cargo run` (or `cargo test` for lib), `cargo clippy --all-targets --all-features -- -D warnings`,
  and a closing one-line rainbow sign-off. Must look great at 80 columns and never exceed `columns`.
- `test/ui.test.js` (node:test): `none` tier output has no `\x1b`; `paint` keeps visible text equal
  to input; banner frames differ between frame 0 and 10 in truecolor; summary contains the name and
  every top-level dir; ASCII fallback has no non-ASCII when unicode=false.
- Put a short usage demo in a comment at the top of summary.js.
